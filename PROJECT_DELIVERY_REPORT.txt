TROUBLESHOOTING QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════

PROBLEM: Node.js not installed
SOLUTION: Download from nodejs.org, restart computer

PROBLEM: MongoDB connection fails
SOLUTION: Check URI in .env, verify credentials

PROBLEM: Google API error
SOLUTION: Verify API key at ai.google.dev

PROBLEM: Port 3000 in use
SOLUTION: Change PORT in .env to 3001

PROBLEM: Can't access http://localhost:5173
SOLUTION: Check frontend is running, port free

See LOCAL_SETUP_GUIDE.md for detailed troubleshooting.
