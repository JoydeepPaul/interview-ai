## 🛠️ TROUBLESHOOTING QUICK REFERENCE

| Problem | Solution |
|---------|----------|
| Node.js not found | Install from nodejs.org, restart computer |
| MongoDB connection error | Check .env URI, verify credentials |
| Google API error | Verify API key, check quota at ai.google.dev |
| Port 3000 in use | Change PORT in .env to 3001 |
| Can't access http://localhost:5173 | Check frontend is running, port 5173 free |
| Blank page after login | Check browser console (F12), check API errors |

See LOCAL_SETUP_GUIDE.md for detailed troubleshooting.
