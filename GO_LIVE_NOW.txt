STEP 2: DEPLOY BACKEND TO RENDER
Time: 15 minutes
─────────────────────────────────

WHERE: https://render.com

WHAT TO DO:
  1. Log in to Render (create free account if needed)
  2. Click "New +" → "Web Service"
  3. Select: "GitHub" (not GitLab)
  4. Find and select: interview-ai
  5. Configure:
     - Name: interview-ai-backend (or similar)
     - Environment: Node
     - Build command: npm install
     - Start command: npm start
     - Region: Singapore (or closest to you)
  6. Click "Advanced" and add Environment Variables:

     MONGODB_URI = mongodb+srv://JOYDEEP:<PASSWORD>@interview-ai-cluster.wsz37k2.mongodb.net/?appName=INTERVIEW-AI-CLUSTER
     GOOGLE_API_KEY = your-api-key-here
     JWT_SECRET = your-secret-here (generate: openssl rand -hex 32)
     FRONTEND_URL = https://interview-ai-xxxx.netlify.app (update later)
     ALLOWED_ORIGINS = https://interview-ai-xxxx.netlify.app (update later)

  7. Click "Create Web Service"
  8. Wait for build to complete (~5-10 minutes)

RESULT:
  ✓ Backend running at: https://interview-ai-backend-xxxx.onrender.com
  ✓ Save this URL for Step 4

🎯 COMMON ISSUES & QUICK FIXES

Issue: "Cannot find module"
  → Render: Check build logs, run `npm install` locally
  → Fix: Commit package-lock.json

Issue: Frontend blank/shows errors
  → Check browser console (F12)
  → Check VITE_API_URL is correct
  → Check backend ALLOWED_ORIGINS includes frontend URL

Issue: Cannot login/register
  → Check MongoDB URI is correct
  → Check database is running
  → Check JWT_SECRET is set

Issue: No questions generate
  → Check Google API key is valid
  → Check API key has quota remaining
  → Check backend logs for errors

Issue: Backend returns 502
  → Check Render logs
  → Check all env variables are set
  → Try manual redeploy
