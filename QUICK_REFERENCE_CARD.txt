STEP 1: PUSH TO GITHUB (10 min)

WHERE: Your computer (Command Prompt)

  cd C:\Users\JOYDEEP PAUL\Desktop\GenAI

RESULT:

───────────────────────────────────────────────────────────────────────────────

STEP 2: RENDER BACKEND (15 min)
────────────────────────────────────────────────────────────────────────────

WHERE: https://render.com/dashboard

ACTION:
  1. Click "New +" → "Web Service"
  2. Select "interview-ai" GitHub repo
  3. Configure:
     - Name: interview-ai-backend
     - Build: npm install
     - Start: npm start
  4. Add Environment Variables:
     MONGODB_URI = mongodb+srv://JOYDEEP:<PASSWORD>@...
     GOOGLE_API_KEY = <your-key>
     JWT_SECRET = <generated-secret>
     FRONTEND_URL = https://interview-ai-xxxx.netlify.app
     ALLOWED_ORIGINS = https://interview-ai-xxxx.netlify.app
  5. Click "Create Web Service"

RESULT:
  ✓ Backend URL: https://interview-ai-backend-xxxx.onrender.com
  ✓ Save this URL!

───────────────────────────────────────────────────────────────────────────────

STEP 3: NETLIFY FRONTEND (10 min)
────────────────────────────────────────────────────────────────────────────

WHERE: https://app.netlify.com

ACTION:
  1. Click "Add new site" → "Import an existing project"
  2. Select GitHub
  3. Find & select "interview-ai" repo
  4. Configure:
     - Build command: cd frontend && npm run build
     - Publish: frontend/dist
     - Base: (empty)
  5. Add Environment Variable:
     VITE_API_URL = https://interview-ai-backend-xxxx.onrender.com
  6. Click "Save & Deploy"

RESULT:
  ✓ Frontend URL: https://interview-ai-xxxx.netlify.app
  ✓ Save this URL!

───────────────────────────────────────────────────────────────────────────────

STEP 4: UPDATE CORS (5 min)
────────────────────────────────────────────────────────────────────────────

WHERE: Render Dashboard

ACTION:
  1. Go to: https://render.com/dashboard
  2. Click: interview-ai-backend
  3. Click: Environment
  4. Update:
     FRONTEND_URL = https://interview-ai-xxxx.netlify.app
     ALLOWED_ORIGINS = https://interview-ai-xxxx.netlify.app
  5. Save (auto-redeploy ~1-2 min)

RESULT:
  ✓ CORS configured
  ✓ Backend auto-redeploys

───────────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────────

TEST 7 - Mobile:

  Expected: Responsive, works ✓

  ✓ All features working

🆘 QUICK TROUBLESHOOTING

ISSUE: Backend won't deploy
  → Check Render build logs
  → Verify npm install runs
  → Check for syntax errors

ISSUE: Frontend blank/errors  
  → Open browser console (F12)
  → Check VITE_API_URL is correct
  → Check backend URL is accessible

ISSUE: Cannot login
  → Check MongoDB URI password
  → Verify database is active
  → Check JWT_SECRET is set

ISSUE: No questions generate
  → Check Google API key is valid
  → Check API has quota
  → Check backend logs

ISSUE: CORS errors
  → Check ALLOWED_ORIGINS setting
  → Ensure Render has redeployed
  → Check frontend URL format
