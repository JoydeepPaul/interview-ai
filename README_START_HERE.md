## 📞 TROUBLESHOOTING

### Common Issues:

**"Node.js not found"**
- Install from https://nodejs.org/
- Restart computer
- Run setup.bat again

**"MongoDB connection error"**
- Check connection string in .env
- Verify credentials
- Ensure IP whitelisted

**"Can't access http://localhost:5173"**
- Check frontend is running
- Check port 5173 is free
- Check browser has no extensions blocking

**"Google API error"**
- Verify API key in .env
- Check at https://ai.google.dev/
- Get new key if needed

See LOCAL_SETUP_GUIDE.md for more troubleshooting.
